打开会话后，输入框旁的「打开工作台」会在右侧浏览器打开 `http://127.0.0.1:18770`。每个浏览器标签页第一次进入会话时会自动打开一次。

浏览器标签由 Harness 自带的右侧浏览器提供。本插件只调用 `openTab('browser', { params: { url } })`。Web 档案里这个浏览器默认关闭，启动补丁会把它打开。

自动打开失败时，点按钮再试。仍不行就在右侧「浏览器」地址栏输入工作台地址。改了端口时，要同步修改 `client.js` 里的 `DEFAULT_STUDIO_URL`。

右侧浏览器的沙箱可能拦下 MP4 下载。导出文件在工作台的 `output/exports/`。
